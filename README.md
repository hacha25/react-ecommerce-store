# hacha Store

Bienvenue sur **hacha Store**, une application e-commerce moderne construite avec React et Vite. Ce projet démontre une expérience d'achat entièrement fonctionnelle avec des fonctionnalités telles que la navigation dans les produits, la gestion du panier et les détails des produits.

## 🚀 Live Demo

🔗 https://react-ecommerce-store-seven.vercel.app/

---
## 🚀 Fonctionnalités

- **Page d'accueil** : Produits en vedette et bannières promotionnelles.
- **Boutique** : Parcourez le catalogue complet des produits.
- **Détails du produit** : Consultez des informations détaillées sur chaque produit.
- **Panier** : Ajoutez des articles, ajustez les quantités et gérez votre panier.
- **Design Réactif** : Optimisé pour les ordinateurs de bureau et les appareils mobiles.
- **Notifications Toast** : Retour d'information en temps réel pour les actions de l'utilisateur (par exemple, ajout au panier).

## 🛠️ Stack Technique

- **Framework Frontend** : [React](https://react.dev/)
- **Outil de Build** : [Vite](https://vitejs.dev/)
- **Style** : [Bootstrap](https://getbootstrap.com/) & CSS Personnalisé
- **Routage** : [React Router](https://reactrouter.com/)
- **Animations** : [Framer Motion](https://www.framer.com/motion/)
- **Icônes** : [React Icons](https://react-icons.github.io/react-icons/)
- **Notifications** : [React Toastify](https://fkhadra.github.io/react-toastify/)

## 📂 Structure du Projet

```
src/
├── assets/          # Ressources statiques (images, etc.)
├── components/      # Composants UI réutilisables (En-tête, Pied de page, etc.)
├── context/         # Contexte React pour la gestion d'état (CartContext)
├── data/            # Données statiques (liste des produits)
├── pages/           # Composants de page (Accueil, Boutique, Panier, etc.)
├── reducer/         # Reducers pour la gestion d'état
├── App.jsx          # Composant principal de l'application
└── main.jsx         # Point d'entrée
```

## 📦 Installation

1.  **Cloner le dépôt :**

    ```bash
    git clone <url-du-dépôt>
    cd e-commerce
    ```

2.  **Installer les dépendances :**

    ```bash
    npm install
    ```

## 🏃‍♂️ Utilisation

1.  **Démarrer le serveur de développement :**

    ```bash
    npm run dev
    ```

2.  **Ouvrir votre navigateur :**
    Naviguez vers `http://localhost:5173` (ou l'URL affichée dans votre terminal).
